如果要配合rimtalk必须要在提示词或者记忆库中进行着重约束，不然会出现殖民者不知道谁被借出去了从而乱说话的情况

关于mod传播，目前暂时不禁止mod被传播以及塞入各种免费整合包，但是请不要用于盈利（该mod将永久免费），如果您看到有付费情况请即时通知我




MOD由纯XML mod转变为C#mod，添加了大量的功能，但是新增了harmony前置需求（另一个前置依旧是皇权）

新增MOD设置界面，将部分功能和概率均做了开关和滑块调整，部分参数支持随机（详情请见MOD设置），增加一键还原按钮和启用任务包按钮

新增了2个任务面板，现在皇家/地方势力都拥有2个任务面板

新增了4条皇家/地方势力剧情线，4条年轻殖民者专属剧情线，2条异象（触手）类剧情线，加上之前的6条剧情线一共16条

为每条剧情线都单独写了对应的负面健康状态和心情影响（名字都是一样的但是说明不同），所有心情加成均为正面，状态则是负面的疼痛系数和移动速度减益。

mod设置内增加了负面健康状态开关，默认为开，关闭之后将不会造成负面属性（仅仅留下带文本的标签）

心情效果和负面健康状态均在mod设置内配有倍率滑条和随机模式，开启随机模式后会使用50%-150%随机的数值倍率

当登机的殖民者低于成年年龄（又高于最低限制），则会有30%概率触发年轻殖民者专属剧情线（会中断当前剧情线并转变为年轻殖民者专属剧情线）

如果殖民者年龄太小又是成年人身材的请尽可能统一调整到成年以上，反之亦然。

异象（触手）类剧情线则是有20%概率独立触发，如果触发了异象（触手）类剧情线则不会触发年轻殖民者专属剧情线转变剧情

年轻殖民者专属剧情线和异象（触手）类剧情线均能在MOD设置自由开关是否启用并调节概率

当前版本已经将出租对象限定为女性，不再允许男性和年龄过低的殖民者登上穿梭机（至于年龄到底是多低任务面板文本会有提示，不满足年龄限制的将无法登机，当然你自己能改的话另说就是）

发送的信件对象实现了和实际出租的殖民者绑定，现在除了降落信件以外，其他信件内都会附带有出租的殖民者的名字，更有利于rimtalk识别讨论对象

任务时长修改为默认2天，可以在mod设置中调节，如果启用了随机任务时长则会变成1-3天

中途通讯信件由固定时间发出改为根据任务时长的一半发出

奖励计算方式修改为根据任务时长计算基础值（500 + 任务天数 × 300），再乘以奖励倍率，可以调节奖励倍率0%～1000%（另外增加一个随机模式，打开后会在50%到200%之间随机一个奖励倍率）

奖励调整为殖民者返回后获取，死亡等问题导致的任务失败将不会收到奖励。

新增怀孕机制，殖民者返回后将进行一次怀孕判断，有15%（年轻殖民者为10%）概率怀孕并触发随机怀孕通知信件文本

怀孕殖民者可以正常生产，生父会保持未知，如果已经怀孕不会重复受孕

mod设置内可以调节是否会怀孕以及怀孕概率（默认正常殖民者15%，过于年轻的10%），并支持年轻殖民者和正常殖民者分开调节（默认全部开启）

新增日志功能，现在任务返回之后会给小人的社交日志列表里面塞入一定数量的日志（日志会偏直接描写），日志时间调整为陆续发生的，更有氛围感（？）

在mod设置中保留了开关，关闭后将不再塞入社交日志

默认塞入全部八个日志，可以在mod设置调节塞入个数，如果少于八个则会随机挑选相应个数的日志，另外增加了一个随机开关，打开后会随机塞入3-5个日志

任务权重默认为5，在mod设置中可以自由调节任务权重
